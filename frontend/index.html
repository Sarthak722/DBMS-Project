🎓 Academic Lab Rubric & Team Contribution Architecture

4-Student Workload Distribution • MySQL 8.0 • Java JDBC • Web System

This DBMS Lab Project was engineered by a 4-person team. The database design began with foundational physical and transactional schemas (Members 1 & 2), extended with reactive automation triggers (Member 3), and optimized with indexing, stored procedures, and analytics (Member 4).

Team Member 1
Physical Venues & Clues
Part 1 Lead
  • 🏛️ SQL DDL: branches, staff, rooms, clues
  • 🔗 FK Hierarchy: Self-referencing prerequisite clue chain (prereq_clue_id)
  • ☕ Java Backend: VenueRoomDAO.java, VenueRoomController.java, Models
  • 💻 Web Views: Chambers Catalog, Branches Directory, Clue Tree
Team Member 2
Teams & Player Roster
Part 2 Lead
  • 🛡️ SQL DDL: teams, players, bookings, hint_usage, payments
  • 🌱 Seed Data: Comprehensive sample dataset (02_seed.sql)
  • ☕ Java Backend: TeamPlayerDAO.java, TeamPlayerController.java, Models
  • 💻 Web Views: Squad Assembly, Player Management, Roster
Team Member 3
Triggers & Game Ops
Part 3 Lead
  • ⚡ SQL Triggers: 3 Dynamic team_size sync triggers + trg_booking_auto_payment
  • 👁️ SQL Views: team_members, branch_phones, player_phones
  • ☕ Java Backend: BookingDAO.java, BookingController.java, Models
  • 💻 Web Views: Game Master Live Console, Stopwatch Countdown, Hint Dispatcher
Team Member 4
Analytics & Optimization
Part 4 Lead
  • ⚙️ Stored Procedure: sp_complete_game_session (Atomic mission finalizer)
  • 🚀 Indexing & Joins: B-Tree Indexes (idx_bookings_timeslot etc.) & Analytics joins
  • ☕ Java Backend: PaymentAnalyticsDAO.java, Controller + Swing Desktop GUI
  • 💻 Web Views: Hall of Fame Leaderboard, Payments Ledger, Financial Analytics
